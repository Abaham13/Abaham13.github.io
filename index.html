Proyectos

Proyecto 1: Sistema de monitoreo

El proyecto trataba de desarrollar un sistema que permita

información de un Arduino, procesarla y almacenarla de manera

organizada. También permite visualizar los datos y controlar

el funcionamiento del sistema durante la lectura.La información

obtenida se guarda para mantener un registro y poder consultarla

posteriormente. De esta manera, el proyecto facilita el manejo,

seguimiento y análisis de los datos recopilados.

Proyecto 2: Inventario

Este proyecto trata de un sistema de inventarios para

que simula ser para una tienda. Este sistema se

implementaron varios de los conocimientos vistos en

Bases de datos 1, como lo fue la creacion de una base de

datos, la gestion en base al modelo CRUD y la implementacion

de roles a cada usuario.
